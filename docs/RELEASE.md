# Proceso de versión y publicación

1. Revisar el estado del ROADMAP y las PR pendientes.
2. Comprobar compatibilidad en la versión objetivo de Brotato y ModLoader.
3. Revisar créditos, licencias y permisos de todo el contenido empaquetado.
4. Ejecutar las validaciones automáticas.
5. Instalar el paquete en un entorno de prueba limpio.
6. Probar configuración, módulos y registros dentro de Brotato.
7. Generar el paquete ZIP final.
8. Preparar changelog y descripción de Workshop.
9. Solicitar aprobación del propietario.
10. Publicar manualmente en Workshop después de la aprobación, siguiendo `docs/WORKSHOP.md`.

Claude puede preparar los archivos y las instrucciones, pero no debe publicar ni actualizar el Workshop sin autorización expresa.
