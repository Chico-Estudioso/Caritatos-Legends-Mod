# Prompts del kit de arranque

Prompts preparados al inicio del proyecto para trabajar con Claude Code. Se conservan como guía de cada tipo de tarea.

Las restricciones que contienen sobre Git (no fusionar PR, preguntar antes de cada paso, etc.) quedaron **sustituidas** por la forma de trabajo acordada con Mauro que figura en `CLAUDE.md`: Claude trabaja con autonomía, fusiona las PR cuando la CI pasa, y todo se publica a nombre de Mauro sin atribuciones de IA. Publicar en Steam Workshop sigue requiriendo su aprobación.

| Prompt | Uso |
|---|---|
| `01_prompt_inicial_investigacion.md` | Investigación inicial y arquitectura |
| `02_prompt_fase0_arranque.md` | Mod mínimo instalable |
| `03_prompt_fase1_core_configuracion.md` | Núcleo modular y configuración |
| `04_plantilla_recuperar_mod_clasico.md` | Recuperar un mod clásico (una leyenda por PR) |
| `05_prompt_actualizacion_compatibilidad.md` | Adaptación a una actualización de Brotato |
| `06_prompt_release_workshop.md` | Preparar una versión para Workshop |
| `99_plantilla_prompt_tarea.md` | Tareas pequeñas fuera del roadmap |
