# Plantilla para pedir una tarea concreta

Copia y completa esta plantilla para una tarea que no tenga un prompt específico.

---

Tarea: `[QUÉ QUIERO]`.

Contexto: fase `[NÚMERO]` del `ROADMAP.md`.

Antes de empezar:
1. Lee `CLAUDE.md`, `AGENTS.md` y los documentos relacionados.
2. Comprueba la rama y el estado de Git.
3. Resume el plan y los archivos que prevés modificar.
4. Pregunta solo si falta una decisión necesaria; no inventes requisitos.

Trabajo:
- Implementa únicamente el alcance indicado.
- No cambies arquitectura compartida sin justificarlo.
- Añade o actualiza pruebas.
- Respeta licencias, créditos y compatibilidad.

Entrega:
- Rama `feat/<nombre>`, `fix/<nombre>`, `chore/<nombre>` o `docs/<nombre>`.
- Commits pequeños con Conventional Commits en español.
- `ROADMAP.md` y `CHANGELOG.md` actualizados cuando corresponda.
- Pull Request con la plantilla del repositorio.

Reglas Git:
- No trabajes sobre `main`.
- No hagas push a `main`.
- No uses `push --force` ni `reset --hard`.
- No cambies mi identidad de Git.
- No fusiones la PR.

Al terminar dime qué has cambiado, qué pruebas has ejecutado, cómo puedo probarlo yo y qué queda pendiente.
